MAZE EDITOR

Draws carrymaze/1 documents — the same thing the generator emits, so the game cannot tell the difference. See MAZE-FORMAT.md.

The important button is CHECK. It walks the maze the way a player would: collecting every key it can reach, opening every lock it has the key for, and seeing whether the exit can be got to. An authored maze has to pass that the same as a generated one.
